title: BLANK WHEN ZERO summary: Show a numeric display field as all spaces when its value is zero. keywords: BLANK WHEN ZERO BLANK ZERO blank zero suppress report edited ---

Syntax

BLANK [ WHEN ] { ZERO | ZEROS | ZEROES }

What it does

BLANK WHEN ZERO makes a field become all spaces whenever zero is moved into it. Any other value is stored as the PICTURE says. It is used on reports, where a column of 0.00 entries is harder to read than empty space.

It goes on an elementary numeric or numeric-edited item whose usage is DISPLAY. A plain numeric item with BLANK WHEN ZERO is treated as numeric-edited, so you use it as the receiving field of a MOVE and for display, not for arithmetic.

An edited picture made only of Zs already turns zero into spaces (see PICTURE). BLANK WHEN ZERO does the same for pictures that show digits with 9, such as Z,ZZ9.99, which would otherwise print 0.00.

Example

With 12.50, all three fields show the number. With zero, the plain edited field shows 0.00, while the two BLANK WHEN ZERO fields are spaces. BLANK ZERO without WHEN means the same thing.
