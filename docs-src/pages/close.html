title: CLOSE summary: Finish with one or more files, writing out anything still waiting. keywords: CLOSE WITH LOCK REEL UNIT NO REWIND implicit CLOSE warning 42 38 07 ---

Syntax

CLOSE { file-name-1 [ { REEL | UNIT } | WITH LOCK | WITH NO REWIND ] } ...

What it does

CLOSE ends the program's use of a file. Anything still waiting to be written goes to disk, and the file is released so other programs (and a later OPEN in this one) can use it. One CLOSE can close several files: CLOSE IN-FILE OUT-FILE.

After CLOSE the file can be opened again, in any mode. Closing a file that isn't open gives status 42.

WITH LOCK

CLOSE file WITH LOCK closes the file and stops this program from opening it again: a later OPEN gives status 38.

REEL, UNIT and NO REWIND

These phrases come from magnetic tape. On a disk file they don't apply: CLOSE REEL and CLOSE UNIT give status 07 and leave the file open; CLOSE WITH NO REWIND closes it with status 07. Just use a plain CLOSE.

Files left open

Files still open when the program ends with STOP RUN are closed for you, but the runtime prints a warning for each one, to remind you to close them yourself.

Example

One OPEN opens IN-F for input and OUT-F for output, and one CLOSE closes both. Closing IN-F again gives 42. After CLOSE WITH LOCK, opening OUT-F gives 38. IN-F is opened again and never closed, so the program ends with the "implicit CLOSE" warning (it goes to the error output, standard error).

SP COBOL notes

The implicit CLOSE warning and the 07 status for REEL / UNIT are kept as GnuCOBOL 3.2 has them.
