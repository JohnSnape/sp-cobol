Syntax

Format 1: level 78
78 constant-name VALUE [ IS ] literal-1 .

Format 2: CONSTANT (COBOL 2002 style)
01 constant-name CONSTANT AS { literal-1 | LENGTH OF data-name-1 } .

What it does

A constant is a name for a value that never changes. It takes no storage: wherever the name appears, the compiler uses the value instead, as if you had typed the literal there. So a constant can go in places where only a literal is allowed, such as the number of occurrences in OCCURS or the length in a PICTURE.

Both forms do the same job. 78 is the older form that GnuCOBOL took over from Micro Focus COBOL; CONSTANT AS is the form in the 2002 COBOL standard, and it can also take the length of an item or of another constant with LENGTH OF.

What you can use one for

  • a table size: OCCURS MAX-ITEMS, and the same name as the loop limit, so changing one line changes both;
  • a size in a PICTURE: PIC X(TITLE-LEN);
  • a value in an expression, a comparison, a MOVE or a DISPLAY, like any literal.

Because it isn't a data item, you can't MOVE anything into a constant or change it in any other way.

Example

MAX-ITEMS sets the table size (5 prices of 5 bytes, 25 bytes) and is also the loop limit and a subscript. TITLE-LEN is the length of the text constant SHOP-NAME, 12, and sizes the HEADING-TXT field to fit it exactly. TAX-RATE is used in a COMPUTE like any number: 50.00 times 0.0775 is 3.875, rounded to 3.88.
