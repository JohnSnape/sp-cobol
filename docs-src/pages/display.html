title: DISPLAY summary: Print literals and data items on the screen (standard output), or send them elsewhere with UPON. keywords: print output show write screen console WITH NO ADVANCING UPON SYSOUT SYSERR CONSOLE stderr END-DISPLAY ENVIRONMENT-NAME ENVIRONMENT-VALUE ARGUMENT-NUMBER COMMAND-LINE ---

Syntax

Format 1: a line of output
DISPLAY { identifier-1 | literal-1 } ...
    [ UPON { SYSOUT | CONSOLE | SYSERR } ]
    [ WITH NO ADVANCING ]
[ END-DISPLAY ]

Format 2: set the environment or the command line
DISPLAY { identifier-1 | literal-1 }
    UPON { ENVIRONMENT-NAME | ENVIRONMENT-VALUE | ARGUMENT-NUMBER | COMMAND-LINE }
[ END-DISPLAY ]

Format 3: on the screen (see SCREEN SECTION)
DISPLAY { identifier-1 AT LINE line-number COL column-number | screen-name }
[ END-DISPLAY ]

What it does

DISPLAY writes the items you list, one after another with nothing in between, and then ends the line. To put a space between two items, list a " " literal between them.

To show a number the way people write it (no leading zeros, commas, a trailing minus), move it to a numeric-edited field first and DISPLAY that.

WITH NO ADVANCING

Leaves the cursor at the end of the output instead of starting a new line, so the next DISPLAY (or what the user types for an ACCEPT) continues on the same line. Use it for prompts.

UPON

UPON SYSOUT and UPON CONSOLE mean the normal output, the same as no UPON phrase. UPON SYSERR writes to standard error, the stream meant for error messages. In a console window both appear on the screen; the difference shows when output is redirected to a file, since > file catches only standard output.

Format 2 doesn't print anything. DISPLAY "NAME" UPON ENVIRONMENT-NAME picks an environment variable and DISPLAY value UPON ENVIRONMENT-VALUE sets it (or use SET ENVIRONMENT). UPON ARGUMENT-NUMBER chooses which command-line argument the next ACCEPT ... FROM ARGUMENT-VALUE reads.

Screens

With AT LINE ... COL ..., or the name of a screen from the SCREEN SECTION, DISPLAY draws on a full screen at a position, with colors. See SCREEN SECTION.

Examples

Each line shows one kind of item. CUST-NAME is PIC X(8), so "ADA" is followed by five spaces before the "!". UNSIGNED-NUM shows its decimal point and leading zeros; the signed and packed items show a sign; the edited item shows exactly the characters it holds. The group prints its two fields run together. The two DISPLAYs with and without NO ADVANCING make one line.

Standard error

All three lines reach the screen. Had the program been run with DISPLAY2 > out.txt, line 2 would still appear on the screen and only lines 1 and 3 would go into the file.

SP COBOL notes

DISPLAY of a national item (PIC N) prints its characters. GnuCOBOL 3.2 prints the raw UTF-16 bytes instead (a zero byte before each letter). See national data.

A line feed inside the displayed data is written as CR LF on Windows, as GnuCOBOL does there. DISPLAY AT LINE/COL and screen DISPLAYs follow SP COBOL's screen rules (see SCREEN SECTION); plain DISPLAY output matches GnuCOBOL byte for byte.
