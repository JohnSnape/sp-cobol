What it does

The ENVIRONMENT DIVISION holds the parts of a program that depend on the machine it runs on and the files it uses. A program that uses no files and no special names can leave the whole division out.

CONFIGURATION SECTION

SOURCE-COMPUTER and OBJECT-COMPUTER name the computer the program is compiled on and runs on. The names are documentation only. One phrase matters: SOURCE-COMPUTER. name WITH DEBUGGING MODE. turns on the debugging lines (D in column 7, see source format). PROGRAM COLLATING SEQUENCE in OBJECT-COMPUTER names an ALPHABET that sets the order used when the program compares text.

SPECIAL-NAMES gives names to things the program needs:

ClauseWhat it does
CRT STATUS IS itemAfter an ACCEPT of a screen, item (a PIC 9(4) field) holds the key that ended the input: 0 for Enter, 1001 for F1, 2005 for Esc, and so on. See SCREEN SECTION.
CURSOR IS itemNames a field holding a screen position (line and column, as LLCC in a PIC 9(4)). Before an ACCEPT of a screen, it says which field the input starts in; afterwards it holds where the cursor was. See the last example.
CURRENCY SIGN IS "c"Uses a different character instead of $ as the currency symbol in PICTURE strings. It can't be a letter that is already a PICTURE symbol (such as E or L).
DECIMAL-POINT IS COMMASwaps the roles of period and comma, the European way: 1234,50 is a number with two decimals, and PICTURE Z.ZZ9,99 prints 1.234,50.
CLASS name IS ...Defines your own class condition: a list of the characters allowed, such as "0" THRU "9" "A" THRU "F". Then IF field IS name is true when every character of the field is in the list.
ALPHABET name IS ...Names a character order: NATIVE (the machine's own), STANDARD-1 (ASCII), EBCDIC (the IBM mainframe order) or a list of literals in the order you want. It is used by PROGRAM COLLATING SEQUENCE and the COLLATING SEQUENCE phrase of SORT. In a list, the characters you name come first, in your order, and every other character follows in the usual order.
SYMBOLIC CHARACTERS name IS nGives a name to a single character by its position in the character set. Positions count from 1, so the character with code 42 (*) is position 43. The name can then be used like a one-character literal.

The clauses of SPECIAL-NAMES are written one after another, and a single period ends the whole paragraph.

INPUT-OUTPUT SECTION

The FILE-CONTROL paragraph has one SELECT entry for each file the program uses. SELECT gives the file the name the program uses for it, ASSIGN TO says which file on disk it is, and ORGANIZATION says how its records are laid out. Each file also needs an FD entry in the FILE SECTION of the DATA DIVISION. The details (ACCESS MODE, RECORD KEY, FILE STATUS, ...) are on the files page.

Example: SYMBOLIC CHARACTERS

Position 43 is * (code 42) and position 46 is - (code 45). STAR and DASH can be used anywhere a one-character literal could.

Example: FILE-CONTROL

The SELECT connects the name NAME-FILE to the disk file NAMES.TXT, a line sequential (plain text) file. The program writes two lines, then reads the first one back.

Example: CRT STATUS

The keystrokes typed "ADA", Tab, "LOVELACE" and then F1. F1 ended the ACCEPT, so KEY-CODE holds 1001.

Example: CLASS and ALPHABET

HEX-DIGIT is a class of the characters 0 to 9 and A to F: 1F3A is all hex digits, 1G3A isn't. The alphabet VOWELS-FIRST puts A, E, I, O and U ahead of every other character, and PROGRAM COLLATING SEQUENCE makes the program compare text in that order. So EGG comes before BOX, and even the literal "U" is less than "B".

Example: DECIMAL-POINT IS COMMA and CURRENCY SIGN

With DECIMAL-POINT IS COMMA, the VALUE 1234,5 means 1234.50 and the edited pictures use . to group thousands and , for the decimals. CURRENCY SIGN makes # the currency symbol: ###.##9,99 floats it next to the first digit, and #**.**9,99 keeps it in the first column with check-protection stars after it. The doubled amount shows the arithmetic is unchanged.

Example: CURSOR IS

CURSOR-POS starts as 0310, line 3 column 10, which is where the LAST field begins. So the ACCEPT starts in LAST instead of FIRST, and the keystrokes "HOPPER" and Enter fill LAST-NAME. Compare the CRT STATUS example, where input starts in the first field.

SP COBOL notes

After the ACCEPT, SP COBOL puts the start of the field the cursor was in into the CURSOR item; GnuCOBOL gives the exact column within that field.
