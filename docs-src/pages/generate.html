title: GENERATE summary: Print a Report Writer detail line, with any headings, footings and page breaks it triggers. keywords: report writer detail line summary reporting control break print report-name ---

Syntax

Format 1: print a detail line
GENERATE detail-group-name

Format 2: summary reporting (totals only)
GENERATE report-name

What it does

GENERATE is the statement that makes a Report Writer report grow. Before it, move the values for the line into the fields the report's SOURCE, SUM and CONTROL clauses name. GENERATE then does, in order, whatever is due:

  1. On the first GENERATE after INITIATE: the report heading and the first page heading.
  2. If a control field changed since the last GENERATE: the control footings (with their totals) for the old value, then the control headings for the new one.
  3. If the lines won't fit on this page: the page footing, a new page, and its page heading.
  4. The detail line itself (Format 1), and adding the values into the SUM counters.

Detail reporting and summary reporting

Format 1 names a TYPE DETAIL group and prints it. Format 2 names the report itself. It does everything in the list above except print a detail line: the totals still add up and the headings and footings still print. That's called summary reporting: a report of totals only, from the same RD.

Example

The same data goes through the same report twice. In pass 1, GENERATE BOX-LINE prints a line for every record, and a TOTAL line each time WS-FRUIT changes. In pass 2, GENERATE FRUIT-REPORT prints no detail lines, only the totals, which come out the same.
