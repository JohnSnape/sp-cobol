title: GOBACK summary: End the current program: return to the caller from a subprogram, or end the run from the main program. keywords: GOBACK STOP RUN EXIT PROGRAM return end program subprogram main program RETURN-CODE exit code ---

Syntax

GOBACK

What it does

GOBACK ends the program it is in. Where control goes depends on how that program was started:

  • In a program that was CALLed, it returns to the caller, which carries on after its CALL.
  • In the main program (the one the run started with), it ends the run, like STOP RUN.

That makes GOBACK the safe choice for ending any program: it does the right thing whether the program is run on its own or called by another.

GOBACK, STOP RUN and EXIT PROGRAM compared

StatementIn the main programIn a called program
GOBACKends the runreturns to the caller
STOP RUNends the runends the whole run, caller and all
EXIT PROGRAMdoes nothing; the next statement runsreturns to the caller

When the run ends, the main program's RETURN-CODE becomes the program's exit code, which a batch file or script can test.
