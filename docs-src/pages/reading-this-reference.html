The syntax boxes

Each statement and clause page starts with a box that shows every way you can write it. The box is a pattern, not a program you can copy as it is. Read it like this:

In the boxMeans
ADD, TO, GIVING UPPERCASE words are COBOL words. Type them as shown (COBOL doesn't care about upper or lower case, but most programs use upper case).
identifier-1, literal-2 Lowercase words in italics are the parts you supply: the name of one of your data items, a number, a quoted string. The digit only tells several of them apart.
[ ROUNDED ]Square brackets: optional. You may leave it out.
{ CORRESPONDING | CORR } Braces with bars: choose exactly one of the choices.
...The part just before it may be repeated, as many times as you need.
Format 1: ...A label. When a statement has several forms, each one gets its own pattern under its own label.

For example, the first form of ADD is shown as

ADD { identifier-1 | literal-1 } ... TO { identifier-2 [ ROUNDED ] } ...

which allows ADD 1 TO COUNTER, ADD PRICE TAX TO TOTAL and ADD 5 TO A B ROUNDED.

Words that are optional "noise", such as IS in IF A IS NUMERIC or ON in ON SIZE ERROR, are shown in brackets too. They don't change what the program does; put them in when they make it read better.

Words you will meet

TermMeaning
data itemA named piece of storage that your program describes in the DATA DIVISION, such as 01 TOTAL PIC 9(5). Other languages call it a variable.
elementary itemA data item that is not divided any further. It has a PICTURE clause (or a USAGE that implies a size).
group itemA data item made of smaller items under it, with higher level numbers. A group has no PICTURE of its own; it is simply all of its parts side by side, and COBOL treats it as one alphanumeric field. See DATA DIVISION and level numbers.
identifierA way of naming data in a statement: a data name, possibly with qualification, subscripts or reference modification, such as CITY OF HOME-ADDRESS or MONTH-NAME (3). See referring to data.
literalA value written straight into the program: 42, -3.5, "HELLO". See literals.
figurative constantA reserved word that stands for a value, like ZERO or SPACES. See figurative constants.
imperative statementA statement that just does something, with no condition of its own: MOVE, DISPLAY, ADD without SIZE ERROR, and so on, or a statement closed by its scope terminator (END-IF, END-ADD, ...). Phrases like ON SIZE ERROR and AT END take imperative statements.
conditionSomething that is true or false, such as A > B or CUST-NAME = SPACES. See conditions.
arithmetic expressionA formula such as PRICE * 1.08 + 2. See arithmetic expressions.
paragraph, sectionNamed blocks of code in the PROCEDURE DIVISION. See program structure.

The examples

Every example is a complete program that you can type in and run. Under each one is exactly what it printed when SP COBOL ran it, and stock GnuCOBOL 3.2 prints the same thing (where it doesn't, the page says so). Examples are written in fixed format, with sequence numbers in columns 1-6, as described in source format.
