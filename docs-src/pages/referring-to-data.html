Syntax

Qualification:
data-name-1 [ { OF | IN } data-name-2 ] ...

Subscripts (items in a table):
data-name ( subscript [ , subscript ] ... )
    subscript:  integer | data-name-3 [ { + | - } integer ] | index-name [ { + | - } integer ]

Reference modification (part of an item):
identifier ( start : [ length ] )

What it does

Most of the time a data item's name is all you need. This page covers the three ways to be more exact. Together they make up an identifier, the thing the syntax boxes on other pages ask for, and they can be combined: SEAT OF SEATS (2, 3), MONTH-NAME (3) (2:2).

Qualification: OF and IN

Two items may have the same name if they are in different groups, like the CITY of a home address and the CITY of a work address. To say which one you mean, add OF (or IN, which means the same) and the name of a group that contains it: CITY OF HOME-ADDRESS. You only need enough qualifiers to make the name unique; A OF B OF C is allowed when one level isn't enough.

Subscripts

An item with an OCCURS clause is a table, and each use of it needs a subscript in parentheses saying which element: MONTH-NAME (2) is the second one. Elements are numbered from 1. A subscript can be:

  • a literal: MONTH-NAME (2);
  • a numeric data item: MONTH-NAME (N);
  • a data item plus or minus a literal (a relative subscript): MONTH-NAME (N + 1).

A table inside a table needs one subscript for each level, outer first, separated by commas or spaces: SEAT (ROW-NO, SEAT-NO).

Indexes

OCCURS ... INDEXED BY name declares an index for the table. An index is used like a subscript, MONTH-NAME (M-IDX), but you change it with SET (SET M-IDX TO 6, SET M-IDX UP BY 1) or PERFORM VARYING, not with MOVE or ADD. Indexes are what SEARCH uses. Relative indexing (M-IDX + 1) is allowed too.

Reference modification

To use part of an item, write the starting position and the length in parentheses with a colon between: CITY (1:3) is the first three characters of CITY. Leave out the length to mean "to the end": CITY (5:). Positions count from 1, and either part can be a data item or an arithmetic expression. The result is always treated as alphanumeric text, even when the item is a number. On a table element, the subscript comes first: MONTH-NAME (3) (2:2).

Keep subscripts between 1 and the OCCURS count. COBOL doesn't check them for you. In stock GnuCOBOL, MONTH-NAME (7) in a six-element table quietly reads whatever bytes lie in memory after the table. SP COBOL keeps each 01 record in its own block of memory, so a subscript that runs off the end of the record stops the program with a .NET error (ArgumentOutOfRangeException) instead.

Example: one of each

The two CITY items are told apart by OF and IN. With N = 4, MONTH-NAME (N) is APR, (N + 1) is MAY and (N - 3) is JAN. The index M-IDX is SET to 6, then down by one. MONTH-TABLE (N:5) takes five characters of the whole table starting at position 4, which crosses from FEB into MAR.

Example: a two-level table

SEATS holds two rows of three seats. SEAT (1, 2) is row 1, seat 2. The second MOVE adds a qualifier as well; it comes before the subscripts. SEAT-ROW (R) is a whole row, shown as three characters.
