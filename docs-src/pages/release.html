title: RELEASE summary: Hand a record to a SORT from inside its INPUT PROCEDURE. keywords: RELEASE FROM INPUT PROCEDURE sort record SD ---

Syntax

RELEASE record-name [ FROM { identifier-1 | literal-1 } ]

What it does

RELEASE is the WRITE of a sort. It is used only in the INPUT PROCEDURE of a SORT, and gives the sort one record: the record of the sort file (the 01 under the SD). The sort keeps every record it is given, and sorts them all when the input procedure ends.

RELEASE record FROM item moves item to the record first, the same as a MOVE followed by RELEASE.

The input procedure decides what to release: it can read a file and skip records it doesn't want, change fields, or make records out of data that never was in a file.

Example

The input procedure splits a sentence into words with UNSTRING and releases each word as a record. The sort then hands them to the output procedure in alphabetical order. "THE" appears twice, so it comes out twice.
