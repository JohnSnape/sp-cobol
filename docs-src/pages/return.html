title: RETURN summary: Take the next sorted or merged record inside an OUTPUT PROCEDURE. keywords: RETURN INTO AT END NOT AT END END-RETURN OUTPUT PROCEDURE sort merge record SD ---

Syntax

RETURN sort-file-name [ RECORD ] [ INTO identifier-1 ]
    AT END imperative-statement-1
    [ NOT AT END imperative-statement-2 ]
[ END-RETURN ]

What it does

RETURN is the READ of a sort. It is used only in the OUTPUT PROCEDURE of a SORT or MERGE. Each RETURN puts the next record, in sorted order, in the sort file's record (the 01 under the SD). Like READ, it takes the sort file name.

When every record has been returned, the AT END statements run. Otherwise NOT AT END runs. A typical output procedure is a loop that RETURNs until AT END sets a flag.

RETURN file INTO item also moves the record to item, like READ INTO.

Don't confuse it with RETURN-CODE or GOBACK: RETURN has nothing to do with leaving a program.

Example

Four people are released in any order and sorted by age. The output procedure RETURNs them INTO a WORKING-STORAGE group and numbers them. After the fourth, RETURN reaches the end and the AT END statements stop the loop.
