title: SET summary: Set or move a table index, turn on a condition name, or point a LINKAGE item at data. keywords: TO UP BY DOWN BY TRUE FALSE index condition-name 88 ADDRESS OF pointer switch ON OFF ENTRY ---

Syntax

Format 1: give an index (or a number) a value
SET { index-name-1 | identifier-1 } ... TO { index-name-2 | identifier-2 | integer-1 }

Format 2: move an index forward or back
SET index-name-1 ... { UP | DOWN } BY { identifier-3 | integer-2 }

Format 3: make a condition name true or false
SET condition-name-1 ... TO { TRUE | FALSE }

Format 4: point a LINKAGE SECTION item at some data
SET ADDRESS OF identifier-4 TO ADDRESS OF identifier-5

What it does

Indexes

An index is the counter named in a table's INDEXED BY clause (see OCCURS). It holds an entry number, but internally it is stored in a form the computer can use quickly, so you can't MOVE to it or ADD to it like an ordinary field. SET is how you change it:

  • SET DX TO 1 points the index at entry 1. The value can be a number, a numeric field, or another index.
  • SET DX UP BY 4 moves it four entries forward; DOWN BY moves it back.
  • SET SLOT TO DX goes the other way: it copies the entry number out of the index into an ordinary numeric field, where you can display it or do arithmetic.

Condition names

A condition name (a level-88 item) stands for one or more values of its parent field. SET ORDER-SHIPPED TO TRUE moves the condition's value (its first value, if it has several) into the parent field, so that the condition becomes true. This reads better than MOVE "S" TO ORDER-STATUS and keeps the actual code letter in one place.

SET ... TO FALSE works only when the 88 item has a FALSE phrase, as in 88 ALL-DONE VALUE "Y" FALSE "N"; it moves the FALSE value into the field.

ADDRESS OF

An item in the LINKAGE SECTION has no storage of its own; normally it describes data passed in by a CALL. SET ADDRESS OF VIEW TO ADDRESS OF GREETING makes VIEW describe the bytes of GREETING, so reading or changing VIEW reads or changes GREETING. This is an advanced feature; most programs never need it.

Examples

The index starts at entry 1 (MON), moves up four to FRI and down two to WED. Setting it from SLOT, which holds 2, points it at TUE, and SET SLOT TO DX copies the 2 back out. SET ORDER-SHIPPED TO TRUE puts "S" in ORDER-STATUS, so the IF finds the condition true. ALL-DONE has a FALSE value, so it can be set either way.

VIEW is a LINKAGE SECTION item. After the SET it describes GREETING's five bytes, so displaying VIEW shows HELLO, and moving WORLD into VIEW changes GREETING.

SP COBOL notes

Not working in this preview, although they compile in GnuCOBOL 3.2:
  • Setting a USAGE POINTER item (SET ptr TO ADDRESS OF x, SET ptr TO NULL): the C# build fails. Use SET ADDRESS OF x TO ADDRESS OF y directly, as in the example.
  • SET switch-name TO ON / OFF and testing the switch's ON STATUS / OFF STATUS conditions (switches declared in SPECIAL-NAMES): the C# build fails. Use an ordinary field with 88-level condition names instead.
  • SET program-pointer TO ENTRY "name" is not supported (see CALL).
