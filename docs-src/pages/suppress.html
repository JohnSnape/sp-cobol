title: SUPPRESS summary: Stop one Report Writer group from printing, from inside a USE BEFORE REPORTING declarative. keywords: SUPPRESS PRINTING USE BEFORE REPORTING declaratives report writer skip footing ---

Syntax

SUPPRESS [ PRINTING ]

What it does

SUPPRESS PRINTING tells the Report Writer not to print the report group that is about to print, this one time. It is only allowed in a USE BEFORE REPORTING section of the DECLARATIVES: that section runs just before its group prints, decides, and may suppress it.

Suppressing a group does not stop anything else. SUM counters are still reset after a suppressed control footing, and the next GENERATE carries on as usual.

Example

The BEFORE-TOTAL section runs before every TEAM-TOTAL footing. While a footing prints, the control field still holds the team that is ending, so WS-TEAM is "SOLO" when SOLO's footing is due, and that total is suppressed. The REDS and BLUES totals print normally.

SP COBOL notes

SUPPRESS and USE BEFORE REPORTING work as in GnuCOBOL 3.2, except for declaratives on DETAIL groups, where SP COBOL fixes a GnuCOBOL bug that doubles the totals (see Report Writer).
