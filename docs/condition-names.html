    Data description

    Condition-names (level 88)

    Give a name to a value or set of values, then test it like a true/false condition.

    Syntax

    88 condition-name { VALUE [ IS ] | VALUES [ ARE ] }
       { literal-1 [ { THROUGH | THRU } literal-2 ] } ...
       [ FALSE [ IS ] literal-3 ] .

Using it
IF [ NOT ] condition-name ...
SET condition-name ... TO TRUE
SET condition-name ... TO FALSE

    What it does

    A level-88 entry comes right under a data item (its conditional variable) and names some of the values that item can have. The name then works as a condition: it is true when the item holds one of those values. Instead of IF GRADE >= 60 AND GRADE <= 100 you write IF PASSED, which says what the test means.

    An 88 takes up no storage. One item may have many 88 entries, and their value lists may overlap: in the example, 100 makes both PASSED and PERFECT true.

    Values, lists and ranges

    List as many values as you need after VALUE or VALUES (the two words mean the same). THRU (or THROUGH) gives a range, both ends included. Values and ranges can be mixed in one entry.

    Where to use them

    Anywhere a condition is allowed: IF, EVALUATE TRUE with WHEN condition-name (see EVALUATE), PERFORM ... UNTIL condition-name (see PERFORM), and with NOT, AND and OR (see Conditions).

    SET TO TRUE and SET TO FALSE

    SET condition-name TO TRUE moves the condition's (first) value into the conditional variable, which makes the condition true. It is a clearer way of writing a flag than MOVE "Y" TO END-FLAG. SET condition-name TO FALSE needs a FALSE phrase in the 88 entry, and moves that value instead.

    Example

    75 is in the range 60 THRU 100 but isn't 100, so PASSED is true and PERFECT is not. SET PERFECT TO TRUE moves 100 into GRADE. "O" is in WARM's list, so EVALUATE takes the first WHEN. The loop runs until SET ALL-DONE TO TRUE puts "Y" in END-FLAG, and SET ALL-DONE TO FALSE puts back the FALSE value, "N".
