    Statements

    CONTINUE

    A statement that does nothing, for places where COBOL needs a statement but you have nothing to do.

    Syntax

    CONTINUE

    What it does

    CONTINUE does nothing, and the program carries on with whatever comes next. It exists because some places in COBOL must hold at least one statement: the branch of an IF, a WHEN of an EVALUATE, or the ON SIZE ERROR of an arithmetic statement. Writing CONTINUE there says "nothing to do in this case" on purpose.

    A common use is an IF whose interesting case is the ELSE: IF BALANCE >= 0 CONTINUE ELSE .... You could reverse the condition instead (IF BALANCE < 0), and often that reads better; CONTINUE is handy when the condition is easier to state the positive way.

    In an EVALUATE, a WHEN with CONTINUE catches a case that needs no action, so it doesn't fall into WHEN OTHER.

    CONTINUE is not the same as NEXT SENTENCE. CONTINUE goes on with the statement after the END-IF; NEXT SENTENCE jumps past the next period, which can skip statements you meant to run. The IF page shows the difference.

    Example

    BALANCE is negative, so the ELSE branch prints the message; had it been zero or more, CONTINUE would have done nothing. CODE-IN is "B", whose WHEN does nothing, so neither "CODE A" nor "UNKNOWN CODE" appears and the program goes straight on to DONE.
