    Statements

    EXIT

    Leave a paragraph, a section, a PERFORM loop or a called program early; or mark the end of a PERFORM THRU range.

    Syntax

    EXIT
EXIT PARAGRAPH
EXIT SECTION
EXIT PERFORM [ CYCLE ]
EXIT PROGRAM

    What it does

    StatementEffect
    EXITNothing. It marks a paragraph that exists only to be the end of a PERFORM ... THRU range or the target of a GO TO.
    EXIT PARAGRAPHSkip the rest of the current paragraph, as if its end had been reached.
    EXIT SECTIONSkip the rest of the current section, including any paragraphs after this one in it.
    EXIT PERFORMLeave the inline PERFORM ... END-PERFORM loop it is in; the program goes on after END-PERFORM. Like break in other languages.
    EXIT PERFORM CYCLESkip the rest of this pass through the inline loop and start the next one (the VARYING item is stepped and the UNTIL test made as usual). Like continue in other languages.
    EXIT PROGRAMIn a called program, return to the caller. In a main program it does nothing. See GOBACK.

    EXIT as an exit paragraph

    Older code performs a range of paragraphs, PERFORM CHECK-IT THRU CHECK-IT-EXIT, and leaves early with GO TO CHECK-IT-EXIT. The last paragraph holds only EXIT. because a paragraph must contain a statement. EXIT PARAGRAPH and EXIT SECTION do the same job without the extra paragraph or the GO TO, and are the better choice in new code.

    EXIT PERFORM and EXIT PERFORM CYCLE belong inside an inline PERFORM (one with END-PERFORM). To leave an out-of-line PERFORM early, use EXIT PARAGRAPH or EXIT SECTION in the performed code.
