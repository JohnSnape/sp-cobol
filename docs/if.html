    Statements

    IF

    Run statements only when a condition is true, with an optional ELSE for when it is false.

    Syntax

    IF condition [ THEN ]
    { statement-1 ... | NEXT SENTENCE }
[ ELSE
    { statement-2 ... | NEXT SENTENCE } ]
[ END-IF ]

    What it does

    IF tests a condition. When it is true, the statements after it run; when it is false, the statements after ELSE run (or nothing, if there is no ELSE). Either way, the program then goes on after END-IF.

    A branch can hold any number of statements, including other IFs. Each IF inside another one is nested, and needs its own END-IF; an ELSE belongs to the nearest IF before it that doesn't already have one. Indent each level so the structure is easy to see, but remember that COBOL ignores the indentation: only END-IF and periods decide where an IF ends.

    Conditions can compare values (BALANCE < 0), test a class (QTY IS NUMERIC), test a sign (AMOUNT IS NEGATIVE), use an 88-level condition name, and be combined with AND, OR and NOT. See conditions.

    Doing nothing in a branch: CONTINUE and NEXT SENTENCE

    A branch must hold something. CONTINUE means "nothing here", and the program goes on after the END-IF. NEXT SENTENCE is older and different: it jumps to just after the next period in the source, skipping everything up to it, even statements after the END-IF. Use CONTINUE.

    The period trap

    A period ends a sentence, and it ends every IF that is still open, however deeply nested. In older code without END-IF, the period was how an IF was closed. If you put a period at the end of a line inside an IF by mistake, the IF stops there and the lines after it run every time, though the indentation says otherwise. The safe habit: close every IF with END-IF, and put periods only at the end of a paragraph.

    Examples

    For 750 the outer condition is false, so the ELSE runs and the nested IF finds it over the limit. For 120 the nested IF's ELSE prints OK. For -30 the first branch runs and the nested IF is never reached.

    CONTINUE, NEXT SENTENCE and the period trap

    N is 5. With CONTINUE, the program goes on after END-IF and prints "AFTER END-IF". With NEXT SENTENCE, it jumps past the next period, so "AFTER END-IF" is skipped and the program resumes at the next sentence. In the last part, N > 7 is false, and "BIG" is not shown. But the period after DISPLAY " BIG" ended the IF, so the next DISPLAY isn't part of it and runs anyway.
