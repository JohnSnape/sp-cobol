    Statements

    INITIATE

    Start a Report Writer report, resetting its page and line counters and its totals.

    Syntax

    INITIATE report-name-1 ...

    What it does

    INITIATE gets a report (an RD in the REPORT SECTION) ready to print. It sets PAGE-COUNTER to 1 and LINE-COUNTER to 0, sets every SUM counter to zero, and forgets the previous values of the control fields. It doesn't print anything: the report heading and the first page heading appear at the first GENERATE.

    The report's file must already be open for output (OPEN OUTPUT). You can name several reports in one INITIATE. Once a report has been ended with TERMINATE, you may INITIATE it again to print it a second time, in the same file or after reopening it.

    Example

    Straight after INITIATE, PAGE-COUNTER is 1 and LINE-COUNTER is 0, and nothing has been printed yet. The report is then printed twice. The second INITIATE starts the page number at 1 again and the TOTAL starts from zero, so it shows 22, not 137. Each run is padded to its 6-line page.

    Report Writer, GENERATE, TERMINATE, OPEN.
