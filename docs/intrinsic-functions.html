    Topics

    Intrinsic functions

    Built-in functions for text, arithmetic, dates, statistics and money, used as FUNCTION name (arguments).

    Syntax

    Format 1: call a function
FUNCTION function-name [ ( argument-1 ... ) ] [ ( start : [ length ] ) ]

Format 2: allow function names without the word FUNCTION
ENVIRONMENT DIVISION.
CONFIGURATION SECTION.
REPOSITORY.
    FUNCTION ALL INTRINSIC.

    What it does

    An intrinsic function is a calculation built into COBOL. You write FUNCTION, the function's name and, in parentheses, its arguments: the values it works on, separated by spaces (commas are allowed too). The function returns a value, which you use where you would use a data item of that kind: in DISPLAY, MOVE, COMPUTE, IF and so on.

    MOVE FUNCTION UPPER-CASE(WS-NAME) TO WS-NAME
COMPUTE WS-ROOT = FUNCTION SQRT(WS-AREA)
IF FUNCTION MOD(WS-YEAR 4) = 0 ...

    Functions return either a number (numeric functions, used in arithmetic such as COMPUTE) or text (alphanumeric functions, used where text goes). A text result can be cut with reference modification, as in FUNCTION UPPER-CASE(WS-TEXT)(3:5), and functions can be nested: FUNCTION LENGTH(FUNCTION TRIM(WS-TEXT)).

    Functions that take "a list of numbers" (MAX, SUM, MEAN, ...) take any number of arguments. GnuCOBOL 3.2 doesn't accept a whole table as ITEM(ALL), so list the items, or add them up in a PERFORM loop.

    Without the word FUNCTION

    FUNCTION ALL INTRINSIC in the REPOSITORY paragraph lets you leave out the word FUNCTION everywhere in the program: DISPLAY UPPER-CASE(WS-NAME). The function names then become reserved words in that program, so you can't use them as data names (no item called SUM or LENGTH).

    The functions

    Every function below works in SP COBOL and gives the same results as GnuCOBOL 3.2.

    Text

    FunctionReturns
    UPPER-CASE(text)the text with letters changed to capitals
    LOWER-CASE(text)the text with letters changed to small letters
    TRIM(text [LEADING | TRAILING])the text without spaces at both ends (or only the front, or only the end)
    REVERSE(text)the characters in reverse order
    LENGTH(item)the number of characters (or bytes) in the item
    BYTE-LENGTH(item)the number of bytes the item takes in storage
    LENGTH-AN(item)the item's length in bytes, as for alphanumeric data
    STORED-CHAR-LENGTH(text)the length without trailing spaces
    CONCATENATE(text ...) / CONCATall the arguments joined into one string
    SUBSTITUTE(text from to ...)the text with every "from" string replaced by its "to" string (pairs may repeat)
    SUBSTITUTE-CASE(text from to ...)the same, ignoring upper and lower case when finding "from"
    CHAR(n)the character at position n of the character set (counting from 1, so CHAR(66) is "A")
    ORD(char)the position of a character in the character set (ORD("A") is 66)
    HEX-OF(item)the item's bytes written as hexadecimal digits
    HEX-TO-CHAR(text)the bytes that a string of hex digits stands for
    BIT-OF(item)the item's bytes written as 0s and 1s
    BIT-TO-CHAR(text)the bytes that a string of 0s and 1s stands for
    NUMVAL(text)the number written in the text, such as " -12.5 " or "12.5CR"
    NUMVAL-C(text [currency])the same, also allowing a currency sign and thousands commas ("$1,234.50")
    NUMVAL-F(text)the number in a floating-point string such as "1.5E+3"
    TEST-NUMVAL(text), TEST-NUMVAL-C, TEST-NUMVAL-F0 if the matching NUMVAL function would accept the text, otherwise the position of the first bad character
    LOCALE-COMPARE(text-1 text-2 [locale])"=", "<" or ">" comparing the two texts by the rules of a language

    Numbers and mathematics

    FunctionReturns
    ABS(n)n without its sign
    SIGN(n)-1, 0 or 1 for a negative, zero or positive n
    INTEGER(n)the largest whole number not greater than n (INTEGER(-3.5) is -4)
    INTEGER-PART(n)n with its decimals dropped (INTEGER-PART(-3.5) is -3)
    FRACTION-PART(n)just the decimals of n, with n's sign
    MOD(a b)the remainder of a divided by b, with b's sign (MOD(-17 5) is 3)
    REM(a b)the remainder of a divided by b, with a's sign (REM(-17 5) is -2)
    SQRT(n)the square root
    FACTORIAL(n)1 x 2 x ... x n
    EXP(n), EXP10(n)e to the power n, 10 to the power n
    LOG(n), LOG10(n)the natural logarithm, the base-10 logarithm
    SIN(n), COS(n), TAN(n)sine, cosine, tangent of an angle in radians
    ASIN(n), ACOS(n), ATAN(n)the angle (in radians) for a sine, cosine, tangent
    PI, Ethe constants π and e (no arguments)
    RANDOM [(seed)]a pseudo-random number from 0 up to (not including) 1; give a seed once to start a repeatable sequence
    HIGHEST-ALGEBRAIC(item), LOWEST-ALGEBRAIC(item)the largest and smallest value the numeric item can hold

    Statistics and money

    FunctionReturns
    MAX(n ...), MIN(n ...)the largest, the smallest argument (they work on text too)
    ORD-MAX(n ...), ORD-MIN(n ...)which argument (1, 2, ...) is the largest, the smallest
    SUM(n ...)the total
    MEAN(n ...)the average
    MEDIAN(n ...)the middle value once sorted (the average of the two middle ones for an even count)
    MIDRANGE(n ...)halfway between the smallest and largest
    RANGE(n ...)largest minus smallest
    VARIANCE(n ...), STANDARD-DEVIATION(n ...)how spread out the values are
    ANNUITY(rate periods)the payment per period that pays off a loan of 1 at that interest rate per period
    PRESENT-VALUE(rate amount ...)what a series of future amounts, one per period, is worth today

    Dates and times

    Many date functions use an integer date: a day number counted from 1 January 1601 (day 1). Turn two dates into day numbers and you can subtract them, or add days and turn the number back into a date.

    FunctionReturns
    CURRENT-DATE21 characters: YYYYMMDDHHMMSSss, then the offset from UTC (+hhmm)
    INTEGER-OF-DATE(yyyymmdd)the day number of a date
    DATE-OF-INTEGER(n)the YYYYMMDD date of a day number
    INTEGER-OF-DAY(yyyyddd)the day number of a year-and-day-of-year date
    DAY-OF-INTEGER(n)the YYYYDDD date of a day number
    TEST-DATE-YYYYMMDD(n), TEST-DAY-YYYYDDD(n)0 if the date is valid; 1, 2 or 3 if the year, month or day part is wrong
    DATE-TO-YYYYMMDD(yymmdd [window year])a date with a 2-digit year expanded to 4 digits
    DAY-TO-YYYYDDD(yyddd [window year])the same for YYDDD dates
    YEAR-TO-YYYY(yy [window year])a 2-digit year expanded to 4 digits
    FORMATTED-DATE(format n)a day number as text in a format such as "YYYY-MM-DD" or "YYYYDDD"
    FORMATTED-TIME(format seconds [offset])seconds past midnight as text in a format such as "hh:mm:ss"
    FORMATTED-DATETIME(format n seconds [offset])a date and time together, in a format such as "YYYY-MM-DDThh:mm:ss"
    FORMATTED-CURRENT-DATE(format)today's date and time in that format
    INTEGER-OF-FORMATTED-DATE(format text)the day number of a formatted date
    SECONDS-FROM-FORMATTED-TIME(format text)the seconds past midnight of a formatted time
    TEST-FORMATTED-DATETIME(format text)0 if the text matches the format and is a valid date/time, otherwise the position of the problem
    SECONDS-PAST-MIDNIGHTthe time now, in seconds since midnight
    COMBINED-DATETIME(n seconds)a day number and seconds as one number, n.sssss
    LOCALE-DATE(yyyymmdd [locale]), LOCALE-TIME(hhmmss [locale]), LOCALE-TIME-FROM-SECONDS(seconds [locale])a date or time written the way the computer's language settings write it
    WHEN-COMPILEDthe date and time the program was compiled

    NUMERIC-DECIMAL-POINT, NUMERIC-THOUSANDS-SEPARATORthe decimal point and thousands separator of the computer's settings
    MONETARY-DECIMAL-POINT, MONETARY-THOUSANDS-SEPARATORthe same, for money amounts
    EXCEPTION-STATUSthe name of the last exception condition (such as EC-SIZE-ZERO-DIVIDE), or spaces
    EXCEPTION-FILEthe file status and file name of the last file error

    EXCEPTION-STATEMENTthe statement that raised the last exception
    MODULE-ID, MODULE-CALLER-IDthis program's name, and the name of the program that called it
    MODULE-SOURCE, MODULE-PATHthe source file name, and the path of the running program
    MODULE-DATE, MODULE-TIME, MODULE-FORMATTED-DATEwhen this program was compiled
    CONTENT-LENGTH(pointer), CONTENT-OF(pointer [length])the length of, and the text at, the data a pointer points to

    Examples

    Text functions

    UPPER-CASE and LOWER-CASE keep the field's 20 characters, spaces included; TRIM removes them. LENGTH of the field is 20, of the trimmed text 12. ORD("A") is 66 because COBOL counts character positions from 1. The (3:5) after UPPER-CASE takes five characters starting at the third. NUMVAL-C reads "1,234.50" as a number that can be stored in a numeric field.

    Numeric functions

    Results go through COMPUTE into an edited field so they print readably. Compare MOD and REM, and INTEGER and INTEGER-PART, on negative numbers. Values displayed straight from a function (MAX, SUM, ...) are shown in a size the function chose.

    Date functions

    25 November 2026 is day 155557 counted from 1 January 1601. Adding 30 and converting back gives 25 December. Because day 1 (1 January 1601) was a Monday, the day number MOD 7 gives the weekday with 0 for Sunday: 3 is Wednesday. TEST-DATE-YYYYMMDD returns 3 for 30 February: the day part is wrong. The example uses fixed dates so its output never changes; CURRENT-DATE gives today's.

    FUNCTION ALL INTRINSIC, and money

    With FUNCTION ALL INTRINSIC in the REPOSITORY, UPPER-CASE and LENGTH need no FUNCTION in front. ANNUITY gives the monthly payment on a loan of 1 at 0.5% a month for 12 months; times 10,000 that is 860.66. PRESENT-VALUE says three yearly payments of 100 are worth 272.32 today at 5% interest.

    SP COBOL notes

    Not implemented, in GnuCOBOL 3.2 or SP COBOL: BASECONVERT, BOOLEAN-OF-INTEGER, CHAR-NATIONAL, CONVERT, DISPLAY-OF, EXCEPTION-FILE-N, EXCEPTION-LOCATION-N, FIND-STRING, INTEGER-OF-BOOLEAN, MODULE-NAME, NATIONAL-OF and STANDARD-COMPARE. The compiler stops with "FUNCTION 'name' is not implemented". For FIND-STRING use INSPECT TALLYING, and for DISPLAY-OF / NATIONAL-OF a MOVE between PIC X and PIC N items.

    Known limits: EXCEPTION-STATUS reports the current exception rather than keeping the last one separately as GnuCOBOL does; EXCEPTION-STATEMENT always returns spaces; CONTENT-OF treats every pointer as NULL.

    Differs from GnuCOBOL 3.2: stock GnuCOBOL's SECONDS-FROM-FORMATTED-TIME can return a wrong number of decimals when the time has a fraction of a second, picking up a scale left over from another function. SP COBOL doesn't. Some odd stock behaviors are kept, so results match: TEST-NUMVAL-C rejects a currency string of more than one character, and SECONDS-PAST-MIDNIGHT ignores the COB_CURRENT_DATE setting.
