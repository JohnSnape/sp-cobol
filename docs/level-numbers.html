    Data description

    Level numbers

    How the numbers in front of data names build records out of groups and elementary items.

    Syntax

    level-number { data-name | FILLER } [ clauses ] .

level-number is one of:
    01-49   an item in a record (01 starts a new record)
    66      another name for a range of items (RENAMES)
    77      a stand-alone elementary item
    78      a named constant
    88      a condition-name (a name for some values)

    What it does

    Every line in the DATA DIVISION that describes data starts with a level number. The number tells COBOL how the item fits into the items around it.

    Groups and elementary items

    An elementary item is a single field: it has a PICTURE (or a USAGE such as COMP-1 that implies its size) and nothing below it. A group item has no PICTURE; it is made up of the items with higher level numbers that follow it. The group ends at the next item whose level number is the same as the group's or lower.

    01 starts a record: the top of a structure, beginning in column 8. Items inside it use any numbers from 02 to 49. The numbers don't have to go up by one; 05, 10, 15 is the usual style, because it leaves room to add a level later. What matters is that items at the same depth use the same number.

    01  CUSTOMER.                  group (the whole record)
    05  CUST-ID     PIC 9(4).  elementary
    05  CUST-NAME.             group inside the group
        10  FIRST-NAME PIC X(6).
        10  LAST-NAME  PIC X(8).

    A group's size and type

    A group takes up exactly the bytes of the items inside it, one after another, with no gaps. Its size is the sum of their sizes. A group is always treated as alphanumeric (PIC X), whatever is inside it: when you MOVE to a group or DISPLAY it, COBOL copies the bytes as they are, without any number conversion. That is why MOVE "GRACE HOPPER" TO CUST-NAME in the example splits the text across FIRST-NAME and LAST-NAME by position.

    FILLER

    Write FILLER (or leave the name out) for an item you never need to refer to, such as a separator or spacing in a print line. It still takes up room and can have a VALUE.

    The special levels

    • 77: an elementary item that is not part of any record. It works like an 01 with a PICTURE; many programmers just use 01.
    • 66: gives another name to a run of items in the record just above it. See RENAMES.
    • 78: a named constant. See Constants.
    • 88: a condition-name attached to the item above it, such as 88 PASSED VALUE 60 THRU 100. See Condition-names.

    Example

    CUSTOMER is 4 + 1 + 14 + 5 = 24 bytes, and displaying it shows all of its items side by side, including the FILLER dash and BALANCE's digits without a decimal point (the point is only implied). CUST-NAME is 6 + 8 = 14 bytes. Moving 12 characters into CUST-NAME fills FIRST-NAME with the first 6 and LAST-NAME with the rest, padded with spaces.
