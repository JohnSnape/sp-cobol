    Data description

    PICTURE

    Describe what an elementary item holds and how big it is, symbol by symbol.

    Syntax

    { PICTURE | PIC } [ IS ] character-string

    What it does

    The PICTURE clause describes an elementary item: what kind of characters it holds and how many. Each symbol in the character string stands for one position (one character of the field), except V, S and P, which take no room in a normal DISPLAY field. A number in parentheses repeats the symbol before it, so 9(5) is the same as 99999 and X(30) is thirty Xs.

    A PICTURE puts an item in one of these categories:

    • numeric (only 9 V S P): a number you can calculate with;
    • alphanumeric (X, or a mix of X 9 A): any characters;
    • alphabetic (only A): letters and spaces;
    • numeric-edited (9 plus editing symbols such as Z , . $ - CR): a number laid out for people to read, used as the receiving field of a MOVE or a GIVING;
    • national (N): Unicode characters, see National data.

    Data symbols

    SymbolMeaningExample
    9One decimal digit.PIC 9(5) holds 0 to 99999.
    XAny character.PIC X(20) holds 20 characters.
    AA letter or a space.PIC A(10)
    VWhere the decimal point is. It is only implied: no "." is stored and it takes no room.PIC 9(3)V99 holds 123.45 in 5 bytes.
    SThe number has a sign. Must come first. Without it, a negative result loses its minus sign.PIC S9(4)
    PA scaling position: an assumed zero that is not stored.PIC 9(3)PPP holds 45000 in 3 bytes (see the third example).
    NOne national (UTF-16) character, 2 bytes.PIC N(10)

    How many digits

    A numeric item can have up to 38 digits in SP COBOL, as in GnuCOBOL 3.2. The last lines of the first example show a PIC S9(38) item holding a 38-digit number and doing arithmetic on it.

    Numeric-edited symbols

    These make a number readable. You don't calculate with an edited field; you MOVE a number into it (or name it in GIVING) and then DISPLAY or WRITE it.

    SymbolWhat it does
    ZA digit, but a leading zero becomes a space.
    *A digit, but a leading zero becomes *. This is check protection: nobody can write extra digits in front of the amount on a check.
    .The actual decimal point, printed. Lines up with the number's decimal point.
    ,A comma, printed. It becomes a space when it falls among suppressed leading zeros.
    $The currency sign. One $ is printed in a fixed place; several ($$$) float: the sign is printed just left of the first digit shown.
    + -A sign. + prints + or -; - prints - for negative numbers and a space otherwise. One at the start or end is fixed; several at the start (----9) float like $$$.
    CR DBAt the right end: printed when the number is negative, spaces when it isn't. Accountants' credit and debit.
    BInserts a space.
    0Inserts a zero.
    /Inserts a slash.

    A numeric-edited picture may also use 9 for a digit that is always shown. If every digit position is Z (or *) and the value is zero, the whole field is spaces (or stars), decimal point included.

    Alphanumeric-edited

    A picture of X or A mixed with B, 0 or / is alphanumeric-edited: a MOVE into it inserts those characters between the moved characters, for example PIC XXXX/XX/XX turns 20261125 into 2026/11/25. The moved text fills the X and A positions from the left; the inserted characters take no characters from it. The third example shows it.

    Example: data symbols

    A DISPLAY shows a numeric item's digits with its implied decimal point as a real ., and a signed item with a leading - or +. Moving -12 into the unsigned 9(3) drops the sign. A(5) and X(5) pad short values with spaces on the right. The 38-digit item keeps every digit through the subtraction.

    Example: edited pictures

    Each number is moved into ten different edited fields. Look at how the zeros in front are replaced: by spaces with Z, by stars with *. The floating $$$,$$9.99 puts the dollar sign right next to the first digit, while $ZZ,ZZ9.99CR keeps it in the first column and adds CR only for the negative number. ----9.99 shows a minus sign only for -987.65, while +++++9 always shows a sign and, having no decimal places, drops the cents. 99B999B99 and 9(5)00 show the inserted spaces and zeros, and the all-Z picture ZZZZZ.ZZ turns zero into a blank field.

    Example: alphanumeric-edited and P scaling

    The first three lines are alphanumeric-edited MOVEs: slashes, spaces (B) and zeros are inserted between the moved characters. 9(3)PPP stores only three digits; the three Ps stand for zeros after them. A DISPLAY shows the assumed zeros (045000), ADD and MOVE work with the full value, and moving 123456 into it keeps only the digits it can hold, so the last three become zeros.
