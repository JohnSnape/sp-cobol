    Data description

    VALUE

    Give a data item the value it starts with when the program begins.

    Syntax

    Format 1: an item's starting value
VALUE [ IS ] literal-1

Format 2: on a level-88 condition-name
{ VALUE [ IS ] | VALUES [ ARE ] } { literal-1 [ { THROUGH | THRU } literal-2 ] } ...

    What it does

    A VALUE clause in WORKING-STORAGE puts a value in the item before the first statement of the program runs. An item without one starts out with spaces if it is alphanumeric and zero if it is numeric, but writing VALUE makes your intent clear.

    The literal must suit the item: a number for a numeric item (it must fit in the PICTURE, or the compiler warns), text in quotes for an alphanumeric one. You can also use a figurative constant: SPACES, ZERO, HIGH-VALUES, LOW-VALUES, QUOTES, or ALL "x" to fill the whole item with a character or pattern.

    VALUE on a group

    A group can have a VALUE too, as long as it is text (or a figurative constant). The text is put into the group's bytes from the left, as if the group were one PIC X field, and the items inside it then hold their part of it. Leave VALUE off the items inside it.

    VALUE in tables

    A VALUE on an item with OCCURS gives every occurrence the same starting value. To start a table with different values, the classic way is to write a group of FILLER items with the values one after another, then REDEFINES that group as a table. The example does this for day names.

    VALUE on condition-names

    On a level-88 item, VALUE doesn't set anything. It lists the values for which the condition is true, and may have several values and ranges with THRU. See Condition-names.

    VALUE versus INITIALIZE

    VALUE is applied once, when the program starts. To reset items while the program runs, use INITIALIZE or MOVE. Note that INITIALIZE doesn't go back to the VALUE: by default it sets numeric items to zero and alphanumeric items to spaces. (INITIALIZE item ALL TO VALUE is the way to put the VALUE clauses back.)

    Give starting values in WORKING-STORAGE. In the LINKAGE SECTION and FILE SECTION, use VALUE only on 88 levels: that storage belongs to the calling program or to the file's records, not to your program.

    Example

    Each item starts with its VALUE: the short literal "HELLO" is padded with spaces, ALL "*" fills STARS, and HIGH-VALUES are bytes of FF. The group HEADER's value is split between H-NAME and H-CITY by position. The day names come from the FILLER values, seen through the redefining table, and every occurrence of CNT starts at 07. After the MOVEs, INITIALIZE sets GREETING to spaces and the CNT items to zero, not back to their VALUE of 7.
